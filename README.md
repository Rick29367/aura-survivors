# AURA SURVIVORS — versão 0.1

Protótipo 2D vertical feito em Godot 4.

## O que já funciona
- Arena vertical com visual provisório desenhado por código.
- Controle por toque/arraste na área inferior.
- Movimento do personagem.
- Inimigos que perseguem o jogador e causam dano por contato.
- Ataque automático ao inimigo mais próximo.
- Drops de XP e aura.
- Subida de nível e escolha de melhorias.
- Ondas que aumentam a dificuldade.
- Tela de fim de jogo e reinício.

## Como testar
1. Instale Godot 4.3 ou superior.
2. Abra o Godot Project Manager.
3. Clique em Importar e selecione este diretório (arquivo project.godot).
4. Execute o projeto.
